What?

TinyEDA is building simple & high performance Electronic Design Automation (EDA) tools and chip design IP to accelerate chip design.

Why?

Most EDA tools were built decades ago (~1980s).
Therefore a lot of these tools were built under assumptions of computing very different to how modern day computing works.
All of these tools have an arcane look / user-experience and require a lot of scripting to get things done.
This is ultimately good for EDA tool vendors since they will happily charge for setting things up and provide you with an environment that just works.
We are changing this by building performant, user-friendly tools, so you don't have to spend time writing tcl / python scripts orchestrating different workflows and can spend time actually working on your product's design.

How?

TinyEDA Studio is an Integrated Design Environment (IDE) for ASIC design to massively accelerate the Physical Design process while providing better PPA (Performance, Placement, Area) results. We also provide users with much better debuggability to trace root causes of errors in the design back to original RTL.
We are creating faster / simpler tools using the following methods:

  • Developing faster algorithms (classic / ML) (for macro placement, place and route & static timing analysis)
  • GPU accelerating massively parallelizable workloads and using SIMD / Vector compute for CPU workloads.
  • Creating well-designed APIs eliminating glue scripting code between tools.

We will also use these tools internally alongside other automated schematic, layout and simulation tooling to create design IP targeting the following industries:

  1. Automotive
  2. Aerospace (Radiation Hardened)
  3. Consumer Electronics
  4. Industrial Automation
  5. Medical
  6. Nuclear (Radiation Hardened)

FAQ

Will i be able to run this fully locally?
Yes, we will have local apps for mac, windows, linux as well as a collaborative webapp
How difficult is it to switch over from my existing EDA suite?
We will provide tooling to port over all your tcl scripts and other tool specific config to make the switching process painless and inexpensive for your org
Mistakes can be expensive, why should we trust results from your software?
We will be formally verifying equivalence where possible and work closely with foundries to qualify our tools to be signoff ready.
